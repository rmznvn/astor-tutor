# Task 10 — Astro i18n: bilingual onboarding page

Build a small English/Russian **Start Here** landing page for the same Astro resource library.

Read in order:

1. [task.md](./task.md) — the challenge and acceptance criteria.
2. [explanation.md](./explanation.md) — concepts, architecture, and interview questions.
3. [solution.md](./solution.md) — complete reference implementation and CSS.

**Do not create a second Astro app.** Implement the feature in the existing `src/` directory on your own task branch. The files in `learning/` are instructions and references, not automatically installed features.

**Prerequisite:** Complete at least Task 01 (the `resources` Content Collection). This task intentionally does not replace the existing `/resources` page or its React filters.

Official documentation:
- https://docs.astro.build/en/guides/internationalization/
- https://docs.astro.build/en/reference/modules/astro-i18n/
