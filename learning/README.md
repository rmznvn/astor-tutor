# Learning roadmap

These tasks are intentionally cumulative.

## Task order

### 01 — Content Collection
Build a reusable Latest Resources section from local content entries.

### 02 — Dynamic Routes
Turn the resources into real detail pages and add article UX such as a sticky TOC and reading progress.

### 03 — React Filtering
Build a filterable resource library and introduce React only for the stateful interaction.

## Rule

Try the task before opening its Solution section.

Each task includes:

- production-style requirements
- Astro concepts
- CSS practice
- interaction/animation practice
- hints
- explanation
- interview questions with sample answers
- a reference solution
- stretch goals
