# Project instructions

## Purpose

This repository is a learning project for Astro and frontend development.

## Teaching rules

When helping with a task:

- Explain the cause or concept before changing code.
- Prefer the smallest reasonable fix.
- Do not refactor unrelated code.
- Explain Astro-specific behavior explicitly.
- Explain why a feature belongs in Astro, React, or plain browser JavaScript.
- Prefer semantic HTML and accessible interactions.
- Mention performance implications when client-side JavaScript is introduced.
- When useful, include an alternative solution.

## CSS learning rules

Each task should practice a different modern CSS technique. Prefer practical techniques such as:

- Grid and flexible responsive layouts
- `clamp()`
- container queries
- custom properties
- `:has()`
- `text-wrap: balance`
- `focus-visible`
- `prefers-reduced-motion`
- pseudo-elements
- sticky positioning
- gradients and subtle motion

Animations should mainly use `transform` and `opacity` when possible.

## Development

Use:

~~~bash
npm run dev
~~~

Before considering a task complete, also run:

~~~bash
npm run build
~~~

## Learning workflow

Do not jump directly to the final solution unless requested. First help the learner reason through the problem, then give hints, then review the learner's attempt.
